# 桥川公众号封面设计

把一篇文章的标题做成一张公众号横版封面：标题是主角，IP 人物是配角，背景只做氛围。

## 第一步：收齐四项输入

| 输入 | 说明 | 缺了怎么办 |
|---|---|---|
| 标题 | 本期文章完整标题，原文照用 | 必须向用户要，不能自己编 |
| IP 人物参考图 | 用户上传的人物形象图 | 问用户要；用户明确不要人物时，按「无人物」处理，排版只看标题位置 |
| 排版编号 | 01–08，见 [references/layouts.md](references/layouts.md) | 根据标题长短推荐一个，说明理由，让用户确认或直接用 |
| 风格编号 | 01–16，见 [references/styles.md](references/styles.md) | 根据文章主题推荐 2–3 个让用户挑；用户说「你定」就直接选一个 |

用户想看风格长什么样时，把 `assets/previews/style-XX.webp` 对应的样图给用户看。样图只用来确认风格质感，样图里的文字、人物和构图都不是本期内容。

推荐排版的经验：
- 标题短（10 字以内）：01、03、07 都稳
- 标题长、有明显的上下两部分：08（主关键词在上，下行内容在右下）
- 想突出人物表情：02、04（特写只改景别，不放大人物）
- 系列感、活泼：05、06

## 第二步：拆标题

从标题里分出三部分，写进提示词里，让生图模型知道谁大谁小：

- **主关键词**：字高 100%，标题里最该被看到的词
- **引导词**：字高约 50%，例如「我用」「手把手教你」「终于」
- **下行内容**：字高约 60%，标题的后半句或补充说明

短标题不用硬拆。英文不自动当成主关键词。标题最多两行，按语义分行，不拆开完整词组。

## 第三步：拼提示词

按下面的模板拼，`{}` 里换成实际内容。「通用规则」整段照抄，一个字都不要删，这是这套模板稳定出图的关键。

```
请按以下要求直接生成一张公众号封面。
标题：{完整标题原文}
标题拆分：主关键词「{主关键词}」，引导词「{引导词}」，下行内容「{下行内容}」
IP形象：使用本次附带的人物参考图
排版：{排版编号和名称}——{排版描述}
风格：{风格编号和名称}

生成一张公众号横版封面，画布比例约2.35比1，交付尺寸900乘383像素；生成器不支持此尺寸时先按同一比例生成更大图片，再等比缩小。四边安全距离至少画布宽度的2%。
标题使用用户输入原文，不加字，不漏字，不重复，不擅自翻译英文。标题最多两行，按语义分行，不拆开完整词组。
视觉权重：标题约80%，人物约15%，背景约5%。这是视觉主次，不是像素面积。标题文字组合尽量横跨画布约80%宽度；允许人物和文字区域在空间上穿插，但不能遮字或遮脸。
单个人物通常不超过画布宽度的18%至22%；多人物模式合计控制在约30%以内。近景模式不恢复成占三分之一画面的巨大半身像。
从标题中识别主关键词、引导词和下行内容。主关键词字高为100%，引导词约50%，下行内容约60%。短标题无需硬拆。英文不自动成为重点。字形清楚优先于装饰效果。
标题第一视觉，人物第二视觉，背景第三视觉。三者用明暗、颜色或材质差异分层。不得同色同亮度糊在一起。文字后使用克制的局部渐变衬底或暗角，平面风格用柔和明暗过渡，不强加立体发光。
人物保持上传IP的脸型、发型、眼镜等身份特征；材质、服装和表现方式跟随所选风格。不能把3D人物原样贴入扁平、像素或剪纸场景。配饰最多1至2件，不干扰文字。
排版只控制人物与标题的位置、景别和数量；风格只控制材质、光线、场景和色彩。风格样图的构图不覆盖所选排版。样图文字和样图人物不作为用户本期内容。
用户本次明确要求优先，其次是四项输入，其次是本模板通用规则，最后才是风格样图。不得沿用旧版30%至45%大人物比例。C4D精致三维不等于全画面透明玻璃。
不加水印、口号、按钮、二维码、额外人物或英文装饰。每次默认生成一张独立封面，不生成样式拼图。

具体排版：{排版描述}
具体风格：{风格描述}
参考图只用于保持人物身份及确认所选风格，不复制示例文案。
```

无人物时：删掉「IP形象」一行，把「视觉权重」改成标题约 85%、背景约 15%，并删掉人物相关的两段规则。

## 第四步：出图或交付提示词

- **有生图工具**（能接收参考图的图像生成工具）：把提示词和 IP 参考图一起传进去，直接出图。
- **没有生图工具**：把拼好的提示词放在一个代码块里交给用户，告诉用户连同 IP 参考图一起贴到支持参考图的生图工具里（如 GPT 生图、即梦、可灵、Midjourney 等）。

默认每次只出一张。用户要多个方案时，换风格或换排版各出一张，不做拼图。

## 第五步：出图后自查

拿到图后按这几条检查，不过关就带着具体问题重新生成：

1. 标题一字不差：没有错字、漏字、多字、重复
2. 标题是第一眼看到的东西，横跨画布约 80% 宽
3. 人物不超过画布宽度的 1/5 左右，没有变成大半身像
4. 人物还是本人：脸型、发型、眼镜等特征都在
5. 人物材质跟风格一致（比如剪纸风格里人物也是剪纸，不是 3D 贴上去的）
6. 文字没被人物或配饰挡住，人脸没被文字挡住
7. 没有多余的水印、口号、英文装饰、二维码或额外人物
8. 比例是 2.35:1，四边留了安全距离

公众号封面在列表里还会被裁成 1:1 小图显示，主关键词最好落在画面中间偏左或偏右的 383×383 区域内。用户在意小图效果时提醒这一点。
