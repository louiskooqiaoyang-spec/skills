# 八种排版

排版只控制人物与标题的位置、景别和数量，不管材质和颜色。

| 编号 | 名称 | 描述 |
|---|---|---|
| 01 | 左人物右标题 | 人物置左侧边缘，标题置中右。 |
| 02 | 左侧特写右标题 | 人物头部在左侧小范围近景裁切，标题置中右；特写只改变景别，不扩大人物占比。 |
| 03 | 左标题右人物 | 标题置中左，人物置右侧边缘。 |
| 04 | 左标题右侧特写 | 标题置中左，人物头部在右侧小范围近景裁切。 |
| 05 | 双人物中央标题 | 同一IP两次放左右角，标题横跨中央；两个人物合计不抢标题。 |
| 06 | 重复人物标题压底 | 同一IP三次小型重复置上方，标题横跨中下部。 |
| 07 | 上标题下方居中人物 | 标题占中上部，人物小型置下方中央。 |
| 08 | 上标题下左人物 | 主关键词置上部，人物小型置左下，原题下行内容置右下；无下行内容时不编造文字。 |
